# Security and privacy

Career Ops is designed to keep consequential actions outside the automation
boundary.

## Threat model

- Unverified, dead, blocked, already-handled, or outside-lane leads fail closed.
- Missing compensation remains unknown; it is never converted into a salary.
- The core has no network, browser, email, messaging, payment, trading, or job
  submission dependency.
- State ledgers are written atomically and should remain local and untracked.
- The public fixture is synthetic. Do not commit resumes, contact information,
  application histories, API keys, cookies, or generated application packages.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow from the repository's
**Security** tab. Do not include a real applicant's personal data in an issue,
discussion, test fixture, or pull request.
