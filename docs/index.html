Architecture

One narrow path, five explicit stages.

The reusable Python core accepts pre-researched records and a caller-supplied local draft callback. It has no network client.

1

Verify

Require live, eligible, unblocked, not already handled.

2

Classify

Use only explicit annualized compensation evidence.

3

Rank

Stretch confirmed, stretch possible, then bridge.

4

Prepare

Checkpoint at most three successful local receipts.

5

Review

The human checks facts and submits outside the engine.

Authority boundary

Automation stops before consequence.

Career Ops may

  • Rank verified lead records
  • Maintain a bounded local queue
  • Invoke a local draft callback
  • Write an atomic state receipt

Only the owner may

  • Confirm personal facts
  • Send messages
  • Submit applications
  • Spend money or trade
